# Редакционные иллюстрации British Bulldog

Сборка из корня репозитория выполняется командой `python scripts/build-british-bulldog-illustrated-pdfs.py` с PyMuPDF, Pillow и Inkscape. Скрипт берёт страницы из организаторских буклетов и записывает `tasks-reading.pdf` рядом с каждым `tasks.pdf`. Иллюстрации изменены внутри исходных страниц, а для лесной сцены добавлен связанный со страницей 2 крупный вид. Редакционные рисунки основаны на иллюстрациях и условиях организатора. Исходные буклеты доступны в архиве отдельно.

- В буклете 2008 года для 5–6 классов сохранена исходная иллюстрация ванной и восстановлен цвет платья из условия №54. Оттенок выбран редакцией. Пять фигур перерисованы по тем же силуэтам и в том же порядке. Номера, описание и варианты ответов взяты из буклета. [Буклет](https://runodog.ru/BB/BB_0809_5-6.pdf) · [Ключ](https://runodog.ru/BB/BB_0809_stat.pdf)
- В буклете 2010 года для 3–4 классов уточнены контуры птиц и белок поверх исходной иллюстрации. По буклету сверены точки опоры птиц, белка на левом стволе и две белки на земле рядом с ёжиком. Остальная композиция взята из буклета. [Буклет](https://runodog.ru/BB/BB_1011_3-4_bw.pdf) · [Ключ](https://runodog.ru/BB/BB_1011_stat.pdf) · [Школьная копия ключа](https://nsportal.ru/sites/default/files/2013/03/10/pravilnye_otvety_2010-2011.docx)
- Для всех вариантов 2012 года для 5–6 классов перерисованы карточки A и C. Сохранены порядок A–B–C, исходная карточка B, продукты, форма посуды, отметка 180° и надпись на бутылке. Порядок инструкций сверен по отдельному ключу каждого варианта. [Буклет 540](https://runodog.ru/BB/BB_1213/Buklet_BB_1213_540_5-6.pdf) · [Ключ 540](https://runodog.ru/BB/BB_1213/BB_1213_answers_540.pdf) · [Буклет 780](https://runodog.ru/BB/BB_1213/Buklet_BB_1213_780_5-6.pdf) · [Ключ 780](https://runodog.ru/BB/BB_1213/BB_1213_answers_780.pdf) · [Буклет 980](https://runodog.ru/BB/BB_1213/Buklet_BB_1213_980_5-6.pdf) · [Ключ 980](https://runodog.ru/BB/BB_1213/BB_1213_answers_980.pdf)
- В буклете 2015 года для 3–4 классов отрисованы персонажи B и D с исходным набором деталей костюма и атрибутов. В буклете для 7–8 классов уточнены контуры иллюстрации №55, в том числе поверхность воды и брызги рядом с рукой. [Буклет 3–4](https://runodog.ru/BB/BB_1516/BB_1516_3-4.pdf) · [Буклет 7–8](https://runodog.ru/BB/BB_1516/BB_1516_7-8.pdf) · [Ключ](https://runodog.ru/BB/BB_1516/BB_1516_answers.pdf)
