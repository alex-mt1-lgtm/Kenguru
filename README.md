Переход по прямой ссылке в новой вкладке даёт чистую попытку. После входа ответы и открытые разборы синхронизируются между устройствами. Пометки на схемах хранятся до перезагрузки страницы. Нумерация и распределение баллов взяты из соответствующего года. На первом шаге показаны исходные данные; готовое решение открывается в пошаговом разборе.

## Рейтинг и достижения

В меню аккаунта доступны общий рейтинг зарегистрированных участников и личные достижения. В общем рейтинге видны имена пользователей, баллы и число решённых задач. Участники с одинаковым числом баллов занимают одно место. За верный ответ перед первым разбором начисляется стоимость задачи в 3, 4 или 5 баллов. Баллы за задачу начисляются один раз на профиль. Ранее открытые разборы засчитываются как изученные. Достижения показывают прогресс по числу решённых задач, сложности и набранным баллам.

Страница `dist/archive.html` открывается по ссылке под уроком и содержит ссылки на 30 полных вариантов для 3–4 классов. За 2000–2026 годы доступны официальные PDF с ответами. Варианты 2000–2026 годов можно решать на сайте. Для выпусков 2001–2019 годов доступны текстовые условия, отдельные рисунки и пошаговые объяснения. В опубликованных таблицах за 1997–1999 годы есть ответы для старших классов. Источники оригиналов — [«Кенгуру плюс»](https://mathkang.ru/rar/) за 1997–2000 годы и [российский оргкомитет](https://ipokengu.ru/konkurs-kenguru/zadachi.html) за 2001–2026 годы.

Во вложенном архиве 5–6 классов доступны 30 официальных выпусков и 894 задачи. У выпусков 2024 и 2026 и первых десяти задач 2000 года есть отдельные анимированные разборы. Для 2021–2023 и 2025 годов добавлены пошаговые объяснения по официальным решениям с иллюстрациями и наглядными вычислениями там, где они относятся к шагу. В остальных задачах можно выбрать вариант и свериться с официальным ключом. Все условия доступны отдельным текстом. Рисунки и графические варианты показаны отдельно, полные PDF остаются в источниках.

## Запуск и исходники
Приложение без зависимостей и сборки: `dist/index.html`, `dist/style.css`, `dist/lessons.js` (задачи 1–8), `dist/four-point-lessons.js` и `dist/five-point-lessons.js` (задачи 9–24), соответствующие `*-scenes.js` (схемы новых групп), `dist/workspace.js` (рисование), `dist/app.js` (анимации и общее управление). Вариант 2000 года разделён на три модуля по баллам и подключается через `dist/years/2000.js`. Модули остальных лет — `dist/years/2020.js` … `2026.js` (2024 сохраняет отдельные ранее разработанные модули). Каждый модуль содержит метаданные варианта, уроки и функции схем. Достаточно статического HTTP-сервера в `dist/`. Привязка к Sites — `.openai/hosting.json`.

Варианты 2001–2019 загружаются из `dist/years/legacy-catalog.js`. Данные пошаговых объяснений лежат в `sources/legacy-lessons`. Команда `python scripts/build-legacy-editions.py --crop --catalog` (PyMuPDF и Pillow) пересоздаёт карточки и каталог из исходных PDF и проверенных границ в `sources/legacy-layout`.

## Возможности
Выбор любой задачи и ответа; от трёх до девяти шагов с прямой навигацией; назад/далее; показ/пауза; повтор текущей задачи; переход к следующей. Адрес меняется при выборе задачи, поэтому адрес страницы можно скопировать и открыть напрямую. Автопоказ не проходит мимо первого шага без самостоятельного выбора. Анимация обновляется через requestAnimationFrame по прошедшему времени, SVG-элементы обновляются без замены всего кадра. Пожарный идёт с постоянной скоростью, а второй отрезок продолжает первый без повторного старта. Пауза сохраняет точное положение и останавливает автоматические переходы; скрытие вкладки также включает паузу. Стрелки переключают шаги, пробел на фоне — показ/пауза. Адаптивная раскладка, крупный текст условия, фокус клавиатуры, SVG-подписи и оригиналы всех 684 задач.

## Самостоятельное решение на схеме
Панель «Твоя схема»: закрашивание клеток протягиванием, карандаш, прямая линия, лестница с перекладинами, выбор цвета, ластик, отмена и очистка. Можно рисовать пальцем или мышью. Очистку также можно отменить. Пометки хранятся отдельно для каждой задачи и шага; для задачи №1 — ещё и для каждого варианта А–Д. В первом шаге №1 можно выбрать рисунок без сетки и рисовать на нём; закрашивание клеток доступно после перехода к разбору. Переключатель А–Д меняет рабочую схему независимо от выбранного ответа. Пометки не меняют исходную схему или официальный ответ. Хранятся в памяти текущей страницы; после перезагрузки сбрасываются.

В задаче №10 ученик сам заполняет пустую таблицу предпочтений и распределяет фрукты. Дети перечислены в порядке условия, а не в порядке решения. Проверка не подставляет отметки, не убирает варианты автоматически и не выбирает ответ про Борю. Схема сохраняется при переходах, «Повтор» очищает её.

Тесты проверяют все шаги и промежуточные кадры, официальный ключ, площади многоугольников, кратчайший путь по графу площадок (BFS) и отсутствие прыжков в маршруте, футбольную цепочку, единственность набора цен, кубики, плитки, сохранение ответов, повтор, паузу и плавное продолжение движения, отсутствие возврата пожарного к началу, рисование по клеткам и построение лестниц, изоляцию пометок, отмену очистки и формулировки о самостоятельном решении. ## Размещение на olympiads.pro

Сайт состоит из файлов в `dist/` и работает на обычном статическом хостинге. В корне сайта должны лежать `index.html`, `archive.html`, файлы JavaScript и папки `assets/` и `years/`. Без входа ответы сохраняются в текущей вкладке.

При изменениях в `main` GitHub Actions запускает проверки и публикует содержимое `dist/` в ветку `olympiads`. Планировщик Рег.ру запускает `scripts/sync-reg-ru.sh`, который забирает новые файлы из публичной ветки. Доступ на запись в GitHub и учётные данные хостинга этому заданию не нужны.

1. Сохраните проверенную версию `scripts/sync-reg-ru.sh` в домашнем каталоге пользователя хостинга как `olympiads-sync.sh`.
2. В ispmanager откройте «Планировщик» и создайте задание каждые 5 минут с командой `/bin/bash "$HOME/olympiads-sync.sh"`. Если ручной запуск ispmanager задаёт другой домашний каталог, передайте явный путь к сайту первым аргументом. Скрипт публикует файлы в указанную папку, а по умолчанию использует `$HOME/www/olympiads.pro`. Результат первой публикации содержит строку `Published olympiads.pro release`.
3. После загрузки файлов направьте `olympiads.pro` на IP-адреса Рег.ру из настроек сайта, установите SSL-сертификат на хостинге и проверьте HTTPS.

Ручная публикация файлов для хостинга доступна через [ZIP-архив ветки olympiads](https://github.com/alex-mt1-lgtm/Kenguru/archive/refs/heads/olympiads.zip). Распакуйте содержимое каталога из архива в корень сайта.

### Аккаунты и восстановление пароля

Для серверных аккаунтов на Рег.ру нужен PHP 8.2 или новее с `pdo_sqlite` и `mbstring`. В ispmanager создайте почтовый ящик `noreply@olympiads.pro` для писем восстановления. При необходимости настройте этот адрес как отправителя для PHP mail и включите DKIM для почтового домена.

Однократно выполните `scripts/init-reg-ru-accounts.sh` с абсолютным путём к домашней папке пользователя хостинга. Скрипт создаёт `olympiads-config.php` рядом с папкой `www`. При первом обращении API создаёт закрытую базу SQLite в `.olympiads-auth/`. PHP должен иметь права чтения конфигурации и записи в этот каталог вне корня сайта. Проверка готовности доступна по `GET /api/auth.php?action=session`.

Аккаунт синхронизирует ответы, открытые разборы, текущий шаг и рейтинг между устройствами. В гостевом режиме достаточно открыть задачу. Восстановление проверяется сквозным сценарием `PHP_BINARY=php python3 tests/account-api-test.py -v` с тестовой доставкой письма.
