# Квадрат с секретом
Русскоязычный интерактивный урок только по задаче №1 «Кенгуру–2024», 3–4 класс.

Приложение без зависимостей: `dist/index.html`, `dist/style.css`, `dist/app.js`. Для локального запуска достаточно статического HTTP-сервера в `dist/`. Sites: `.openai/hosting.json`.

## Источники и математика
Полные официальные PDF сохранены в `sources/`. Использованы https://ipokengu.ru/public/task/kenguru_2024_class_3-4.pdf и https://ipokengu.ru/public/task/kenguru_2024_solution.pdf . Из первого PDF визуально проверены все пять рисунков задачи №1. Точный фрагмент — `dist/assets/original-task1.png`. Другие задачи в урок не включены.

Координаты разделяющих линий задаются в исходной сетке 4×4. Площади многоугольников проверены формулой площади: А, Б, В, Г — 8 и 8; Д — 7 и 9. Оранжевая часть Д: 3+1+3=7; зелёная: 16−7=9. Официальные решения подтверждают ответ Д (раздел 3–4 класс, задача 1).

## Управление
Выбор ответа без немедленного раскрытия решения; пять шагов; назад/далее; автоматический показ с паузой; повтор со сбросом выбора. Стрелки переключают шаги, пробел на фоне включает/приостанавливает показ. Автопоказ приостанавливается при скрытии вкладки. Адаптивная раскладка, подписи SVG, видимый фокус, reduced-motion.

## Проверки
`node --check dist/app.js`. Проверены площади всех пяти полигонов, 7+9 клеток, все 25 сочетаний выбранного ответа и шага, повтор, показ/пауза и границы шагов через Node VM с DOM-заглушкой. Облачный Sites preview на первой попытке сообщил relay readiness timeout; визуальная браузерная проверка ограничена инфраструктурой.
