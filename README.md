# Восемь открытий · Кенгуру–2024

Русскоязычные интерактивные разборы **всех восьми задач на 3 балла** для 3–4 классов. Пять шагов в каждой задаче: самостоятельный ответ, идея, схема, наглядные действия, проверка. Задачи на 4 и 5 баллов не включены.

## Запуск и исходники
Приложение без зависимостей и сборки: `dist/index.html`, `dist/style.css`, `dist/lessons.js` (условия и объяснения), `dist/app.js` (схемы, анимации, управление). Достаточно статического HTTP-сервера в `dist/`. Привязка приватного Sites — `.openai/hosting.json`.

## Возможности
Выбор любой задачи и ответа; пять шагов с прямой навигацией; назад/далее; показ/пауза; повтор текущей задачи; переход к следующей. Выбранные ответы и текущие шаги сохраняются в памяти при переключении задач. Автопоказ не проходит мимо первого шага без самостоятельного выбора. Анимация обновляется через requestAnimationFrame по прошедшему времени, SVG-элементы обновляются без замены всего кадра. Пожарный идёт с постоянной скоростью, а второй отрезок продолжает первый без повторного старта. Пауза сохраняет точное положение и останавливает автоматические переходы; скрытие вкладки также включает паузу. Стрелки переключают шаги, пробел на фоне — показ/пауза. Адаптивная раскладка, фокус клавиатуры, SVG-подписи, оригиналы всех восьми задач.

## Самостоятельное решение на схеме
Панель «Твоя схема»: закрашивание клеток протягиванием, карандаш, прямая линия, лестница с перекладинами, выбор цвета, ластик, отмена и очистка. Можно рисовать пальцем или мышью. Очистку также можно отменить. Пометки хранятся отдельно для каждой задачи и шага; для задачи №1 — ещё и для каждого варианта А–Д. В первом шаге №1 можно выбрать рисунок и самостоятельно его закрашивать. Пометки не меняют исходную схему или официальный ответ. Хранятся в памяти текущей страницы; после перезагрузки сбрасываются.

## Проверки
`node --check dist/app.js`

`node --check dist/lessons.js`

`node --test tests/lesson.test.cjs`

Тесты проверяют все 40 сцен и промежуточные кадры, официальный ключ, площади многоугольников, кратчайший путь по графу площадок (BFS) и отсутствие прыжков в маршруте, футбольную цепочку, единственность набора цен, кубики, плитки, сохранение ответов, повтор, паузу и плавное продолжение движения, отсутствие возврата пожарного к началу, рисование по клеткам и построение лестниц, изоляцию пометок, отмену очистки и формулировки о самостоятельном решении. Это проверки логики с DOM-заглушкой, не браузерные тесты.

Облачный `sites-preview start /workspace/Kenguru` сообщил `relay could not open browser port 4173: timed out waiting for relay readiness`. Визуальная браузерная проверка предпросмотра не выполнена из-за инфраструктуры. Публикация выполняется через приватный Sites; доступ владельца сохранён.
